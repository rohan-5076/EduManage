# EduManage 🎓

A full-stack Student Management System built using the MERN stack.

EduManage is designed to manage students, teachers, courses, subjects, attendance, exams, fees, notices, results, and other academic activities through a centralized platform.

## 🚀 Features

### 👨‍🎓 Student Management
- Add students
- View student list
- Student profile
- Student dashboard
- Student course information
- Student subjects

### 👨‍🏫 Teacher Management
- Add teachers
- View teachers
- Teacher dashboard
- Teacher settings

### 📚 Academic Management
- Course management
- Subject management
- Semester management
- Exam management
- Marks entry
- Results and grades

### 📅 Attendance
- Record student attendance
- View attendance
- Manage attendance records

### 💰 Fees
- Collect student fees
- View fee records

### 📢 Notices
- Add notices
- View notices
- Student notice section

### 🔐 Authentication
- Student login
- Teacher login
- JWT authentication
- Protected routes

### 🤖 AI Features
- AI chat functionality
- AI service integration

## 🛠️ Tech Stack

### Frontend

### Backend
